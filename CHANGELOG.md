# Changelog

## Unreleased — 3.0 development

### Improvements

- Added a Generate page that builds a randomized PalSchema ZIP from the selected PAK and USMAP files, with progress, cancellation and save handling for the desktop and browser builds.
- Added multi-template management to the Randomizer settings page: create, rename, delete with undo, and import or export templates as YAML or JSON. Templates are stored as YAML files in the local Templates folder.
- Extended the Randomizer settings page with Area Group Type and Area Selections controls. The remaining settings categories are not available yet.
- Improved startup reliability and handling of errors when loading game files.
- Security updates.

Existing settings and templates remain compatible.

The redesigned interface and browser version are still under development. Generation is available; the spawn
editing interface and the remaining settings categories are not available in the new build yet.
